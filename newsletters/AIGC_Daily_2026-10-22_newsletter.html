Claude Mods：彻底颠覆 Harness

这篇文章讨论的不是“怎样让 Claude 多会几个工具”，而是一个更根本的问题：当 agent 开始替人工作，究竟谁应该拥有代理的界面与节奏。作者把 Claude Mods 视为一种早期的 Attention Interface，指出传统 agent harness（代理运行外壳）是面向机器的，把工具、权限、上下文和执行步骤编排给模型；新的范式则把 harness 翻转过来，让它面向人，把人的意图、注意力、反馈和临时接管放进代理的工作回路。借此，agent 不再只是聊天框背后自动跑完任务的黑箱，而有了可以观察、调节和协作的操作层。

文章最有价值的地方，是没有把“模型更强”与“代理更好用”混为一谈：同一底座模型，工具怎样呈现、状态是否可见、何时需要确认，都会改变人机协作的效率与信任。它也把采用率问题拉回 harness 设计，思考代理究竟是在服务人的目标，还是只在优化一个脱离情境的任务完成率。为什么值得读：它提供了一套重新审视 Agent 产品的语言，适合做工具、交互或工作流的人对照检查自己的系统，而不只是追逐模型发布。
