OpenRouter：从种子轮到Stripe级别——与OpenRouter的Alex Atallah和AMP的Anjney Midha

OpenRouter 是当下最重要的 LLM 路由与聚合基础设施——它让开发者用一个 API Key 就能调用几乎所有主流模型。这期 Latent.Space 长访谈由 Alex Atallah 与 AMP 的 Anjney Midha 一起复盘了 OpenRouter 从种子轮到被 Stripe 以 70 亿美元收购的完整历程，以及他们如何精准踩中"模型数量爆炸"这个时代窗口。

核心论断很直接：2023 年绝大多数人不相信前沿模型实验室能超过一两家，结果短短两年冒出来几十家。模型一多，"在哪个模型上跑、用什么价跑、怎样组合调用"就成了独立的技术命题，而 OpenRouter 把这件事做成了产品对做 AI Agent 的人来说，这个判断尤为关键：Agent 的生产环境几乎一定要做模型路由——不同子任务分派到不同模型、用不同成本跑——而路由层本身就是 Agent 性能与成本优化的核心变量之一。访谈还聊到了 unit economics、与模型厂商的关系博弈，以及为什么 Stripe 这种支付基础设施公司愿意为"模型中间层"开出天价。

🔸
席卷当今科技行业的悲伤、孤独与职业倦怠 | Molly Graham

Molly Graham 重访了她几年前那篇广为流传的职业建议文章，核心议题是：在 AI Agent 全面渗透工作流之后，"委派"这件事的底层逻辑正在发生根本性变化。

她最锋利的一个论断是——把任务委派给一个 Agent 和委派给一个人，表面上都是"交出去"，但中间过程完全不同。人类委派时，反馈循环、信任建立、上下文协商是同步发生的，这些"软过程"恰恰是管理工作中最有价值的部分；而 Agent 委派则把这些统统压缩成了一次 prompt 和一次输出。文章没有停留在"AI 会不会取代我"这种表层恐慌，而是更深地追问：当 Agent 吃掉了所有中间层执行任务之后，管理工作本身的"人际意义"还剩什么？为什么 grief、loneliness、burnout 这些情绪在 AI 工具普及之后反而在加剧？
