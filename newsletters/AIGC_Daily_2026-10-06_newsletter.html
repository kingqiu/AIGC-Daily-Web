将AI智能体连接到企业知识

企业里喂给 AI Agent 的数据已经够多了，但它们仍然表现得像个"什么都知道、什么都不真懂"的实习生。这篇文章核心探讨的是：数据（data）和知识（knowledge）之间那道容易被忽视的鸿沟——前者只是事实，后者是"这些事实在我这个公司里到底意味着什么"的上下文理解。没有这层理解，Agent 再强也只能给出泛泛的答案。

文章最有价值的洞察在于：企业级 Agent 的瓶颈往往不是模型能力，而是知识接入（knowledge grounding）。作者详细拆解了把 Agent 接到企业知识体系时面临的真实工程难题——从权限隔离、上下文窗口的取舍，到如何让 Agent 在调用知识时"知道自己不知道什么"。文中引用了多位企业 AI 负责人的一线判断，认为当前大多数 Agent 落地失败的原因，是把 RAG 当成了知识工程的全部。

LLM盲点：为什么模型会遗忘提示词中间的内容

你有没有过这种体验：精心写了一段 prompt，把最关键的指令放在正中间，结果模型偏偏把那段给"吃掉了"？这篇文章讲的就是这个让无数 prompt engineer 吃瘪的现象——Lost in the Middle，中段信息遗忘。
