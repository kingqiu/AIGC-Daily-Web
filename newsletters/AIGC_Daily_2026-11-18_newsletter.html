⭐ 20.0K

如果你正在把 AI Agent 接入聊天界面、流式工作台或多代理应用，常会碰到一个麻烦：不同框架输出 token、调用工具、共享状态、等待人工确认的方式各不相同，前端只能写一堆定制适配。AG-UI 就是为这类场景而来的开放协议，用统一、基于事件的双向数据流，把 Agent 的生成、工具调用、状态更新、人工介入乃至子 Agent 协作传到客户端，并让前端按统一事件渲染和回传操作。项目以 TypeScript 为主，提供 npm 的 @ag-ui/core、Python 包 ag-ui-protocol，以及规范、文档和可运行示例，接入路径比较清晰。它不同于绑定某个模型或 Agent 框架的 SDK，更像一个前后端都能采用的“插座标准”：换框架不必重写 UI，也能让现有应用更容易拥抱 Agent，值得关注。
