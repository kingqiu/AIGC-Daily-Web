推出 ChatGPT 钱包

OpenAI 推出 ChatGPT Wallet，把支付能力直接装进 ChatGPT Work、Codex 和 dots 等 agent 场景：用户批准后，agent 可以代为完成购买，并沿用现有银行卡的消费者保护机制。目前，这项能力先向美国 Pro 用户有限开放。

The Sequence Robotics - 第971期：机器人应该在工作中学习

这篇 The Sequence Robotics 长文讨论一个很现实的问题：机器人能否在进入真实工作环境后持续进步。Tutor Intelligence 的尝试，是把机器人完成的有价值工作、人类提供的指导和仿真训练共同转化为新的智能，而不是依赖一套离线、封闭的数据集。

🔸
免费直播大师班：打造能在现实世界中运行的AI代理

这篇文章围绕一个比“让模型调用几个工具”更实际的问题：AI Agent 如何在真实环境中可靠工作。它给出的工程骨架包括四部分——context 让 Agent 理解当前状态，tools 让它采取行动，guardrails 限制行动边界，checks 则验证行动结果。

其核心判断是，Agent 的失败通常不能只靠修改 prompt 解决。可靠性来自一条完整闭环：先获得足够且相关的上下文，再选择合适工具执行，最后检查结果并决定是否重试、升级给人或停止。任何一个环节缺失，都可能让看似聪明的 Agent 在 Demo 中顺利运转，却在生产环境中失控。
