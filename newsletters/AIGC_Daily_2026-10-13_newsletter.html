Anthropic的动态工作流如何协调Claude智能体

当一个项目大到单个 Claude Agent 装不下的时候，应该怎么办？Anthropic 在 AI Engineer New York 上给出了答案：Dynamic Workflows——一套让多个 Agent 协同工作的编排机制，直接从 Unix 和 Linux 的设计哲学里取经。

文章最有价值的部分，是 Anthropic 对"为什么不直接堆 Agent 就完事了"的反思。简单堆叠多 Agent 会让开发者淹没在协调开销里，这和早期 Unix 系统试图把所有功能塞进一个巨型二进制文件的教训如出一辙。文中将 Unix 的"组合优于集成"原则映射到 Agent 世界：每个 Agent 应该有明确的小职责，之间通过清晰、可组合的接口协作，而不是写一个无所不能的超级 Agent。这种思路对正在做多智能体编排的人来说几乎是现成的架构蓝图。
