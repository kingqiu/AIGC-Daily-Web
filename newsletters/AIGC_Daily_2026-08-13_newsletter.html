鸿海第四季度将开始出货英伟达Vera Rubin平台

英伟达的下一代 Vera Rubin 平台要来了。鸿海确认将在今年第四季度开始出货这款新品，而 Vera Rubin 本身已经进入全面量产阶段。相较上一代 Grace Blackwell，Vera Rubin 在大规模 AI Agent 工作负载下能实现最高 10 倍的吞吐量提升——这个数字相当炸裂。

为什么这个节点值得关注？因为 Vera Rubin 不只是一次常规升级。当下整个行业的算力瓶颈正在从"训练"转向"推理"，尤其是 Agent 类应用对实时性的要求越来越高。10 倍吞吐意味着同样的硬件成本可以服务 10 倍的用户请求，或者用更少的卡跑同样多的 Agent——这会直接改写 Agent 类产品的商业模型。

亚马逊将默认使用Twitch主播的内容进行训练，除非他们选择退出

Amazon 旗下直播平台 Twitch 最近做了一个让创作者圈炸锅的决定：从今天起，平台会默认拿主播的直播内容来训练 AI 模型，想保住自己数据的主播必须主动 opt-out（选择退出）。Twitch 的 CPO Mike Minton 在直播中回应质疑时说了句大实话："如果改成 opt-in，根本不会有人参与进来。"

这话听起来很"坦诚"，但本质上是把举证责任甩给了创作者。在默认开启的设定下，绝大多数主播根本不会注意到这个选项，等发现的时候自己的内容可能早就进了训练集。这跟当年 Facebook 偷偷做情绪实验、LinkedIn 默认同步通讯录的套路如出一辙。

使用可信数据扩展AI代理

MIT Technology Review 这篇深度报道切入了一个企业AI落地中最被低估的瓶颈——数据。当 Agentic AI 被大规模部署时，文章指出，ROI 的实现不取决于模型多强，而取决于支撑 Agent 推理与执行的数据底座是否可靠、可追溯、可治理。文章的核心论点是：很多组织在 Agent 项目上投入巨大却难以兑现预期收益，根本原因在于数据基础设施滞后。Agent 不同于传统软件，它在运行时不断消费数据、产生决策，而这些决策又回流到系统中，形成复杂的数据循环。没有高质量的数据治理，Agent 的规模化部署就会从"赋能工具"退化为"新型数据负债"。文章还梳理了企业在扩展 AI Agent 时面临的数据质量、隐私合规、实时性等核心挑战。市面上充斥着对 Agent 能力的乐观叙事，却少有文章认真拆解企业规模化背后的工程现实。对于任何考虑在组织内部系统化推进 Agent 的决策者来说，这是一份冷静的、操作导向的参考。
